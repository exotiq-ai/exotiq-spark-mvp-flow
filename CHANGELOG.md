# Changelog

One line per shipped change, newest first: date (UTC) — what changed — why.

- 2026-11-16 — Team defaults (minimum rental rate, default deposit, gas / re-fuelling fee) are set once for the team in Fleet → Pricing; the gas fee now lives on the team (migration 20261116010000, backfilled from each owner's saved values) and the minimum rate is saved where pricing reads it — the old Settings field saved the minimum rate to the signed-in person's own settings, where nothing read it, and each staff member could have a different gas fee.
- 2026-11-16 — Rate tiers (daily, 3-hour, 6-hour, multi-day) and each car's deposit hold moved from MotorIQ to Fleet → Pricing as one table beside mileage; the "% of daily" rule fills rows for review instead of saving at once; the minimum rate applies only to rates being changed — pricing was split across MotorIQ and Settings.
- 2026-11-16 — Fleet → Pricing (new tab): team mileage default plus every car's miles/day, per-mile rate and an Unlimited switch in one table; managers edit cars, only the team owner edits team defaults (as the database already enforces); unlimited cars are never charged overage (flag copied onto each booking by a trigger; migration 20261116000000) — operators had to open each car to set mileage and could not offer unlimited miles.
- 2026-11-16 — Tablets start with the sidebar collapsed and show the header search from 1024 px; Fleet header buttons wrap on phones; vehicle menus have 40 px touch targets and names; Bookings tabs read Overview/Calendar/Payments; the phone header names the Fleet page — at 768 px the header overlapped itself, Import was cut off, and Fleet was labelled "Dashboard".
- 2026-11-16 — Dashboard shows content in ~2 s instead of ~7.4 s on a revisit (Home tab: 0.8 s instead of 9.3 s): MotorIQ time-zone helpers reuse one formatter per zone, customer notes no longer hold the dashboard on loading, the signed-in user keeps one identity, role and profile are shared lookups, the subscription check runs once per user — the overview rebuilt an Intl formatter for every day of every booking and loaded its data twice.
- 2026-11-16 — Mileage overage: included miles = miles/day × days (booked, or kept when late), shown with the working at check-in and in Record Payment; overage rate is a free $X.XX field; no invented 250 mi / $1.50 / $0.50 fallbacks — check-in compared a whole trip to one day's allowance and overcharged multi-day rentals.
- 2026-11-16 — `.env` is no longer tracked; `.env.example` shows the variables and CI uses placeholders — the tracked file still named the retired Lovable backend, while production takes its values from Netlify.
- 2026-11-14 — Super Admin: a marketplace request whose platform fee is not confirmed shows "Confirm fee to approve"; errors show their real message (`describeError`) — approvals failed with "[object Object]".
- 2026-11-13 — Payment totals count only the operator's own payments; the Exotiq charge is shown on its own line; Stripe Checkout notes the separate EXOTIQ RENT charge — a $2 rental showed a negative balance.
- 2026-11-13 — Add Vehicle accepts a blank Year; signed-in users can delete vehicle-photo files again — save refused a blank year; replaced photos left files behind.
- 2026-11-13 — Backend moved from Lovable Cloud to the owned Supabase project; Command Center hosted on Netlify.
